Explore Earth on foot from an ultraFLIGHT Explorer or Rocket Earth chart. Dismount on solid ground and run /cubicflight surface. Your ship stays on the chart. Walk on the cubic terrain, then use /cubicflight launchsite to return at your current projected location. After re-entry, a grounded, dismounted player can transfer again. Use /cubicflight off to cancel.

Install on client and server with Java 21, Minecraft 1.21.1, NeoForge (tested on 21.1.259), ultraFLIGHT 0.3.6 and its dependencies. Choose exactly one terrain provider per save:

• Geographic Earth: Earth Platform 0.1.0-alpha.73, released NeoForge file earthplatform-combined-73.jar (github.com/pirut/earth-platform/releases/tag/combined-73).
• Seeded Highlands: standalone Chunks3 0.1.0-alpha.1. The tested historical Alpha file is chunks3-0.1.0-alpha.1.jar (SHA-256 0f9e87d1218ac839a14ffff31497852c234b795ca4db7b47487668bb305af01e). The later NeoForge Beta with the same version number is a different build and was not tested.

Dedicated-server tests covered transfers, ascent, descent and automatic re-entry. A graphical client tested geographic terrain transfer and command-driven flight. Manual cockpit flight and a client orbital round trip remain unverified.
