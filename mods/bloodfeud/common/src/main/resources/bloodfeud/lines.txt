# What Brutes say. All of it written for Blood Feud.
#
# Each [section] is a pool. A Brute picks a line it hasn't said to anyone lately, so the more lines a pool has,
# the longer it stays fresh. A line is skipped when one of its words can't be filled in right now.
#
#   {player}  the player's name          {name}    the Brute's name       {times}  how many times (in words)
#   {pack}    its pack ("the Mossy Bog Pack")    {home}  where the pack lives ("Mossy Bog")
#   {king}    the name of the King it kneels to  {item}  the thing it stole from the player
#   {weapon}  what the player is holding         {days}  how long since it last saw the player ("three days")
#   {scar}    what the player did to its body    {kin}   what it calls its own kind
#
# Family pools (greet.rotten, ...) and rank pools (greet.king, ...) mix in with the memory pools, so the same
# memory sounds different coming from a drowned Boss than from a pillager nobody.
