claude talks to Claude Code from this computer. It runs on your PC, signed in as you, and works on your CC computers through CC: Agent: writing programs, running them, reading errors, using peripherals and turtles.

ex:
"claude" opens the chat.
"claude make a program that shows the time on the left monitor" starts with that request.

In the chat: /model, /effort and /mode (Shift+Tab) change how it works, /resume goes back to an earlier conversation, /new starts over, /help lists everything, /exit leaves. Other /commands go to the agent. Click answers when it asks you something. Hold Ctrl+T to stop a reply.

"claude --tui" runs Claude Code's own full screen instead, on the biggest advanced monitor attached (or this screen if there's none). Type on this computer; its screen follows the prompt. "claude --tui left" picks a monitor, "claude --tui term" uses this screen. Hold Ctrl+T to quit.

Needs Claude Code installed and signed in on your PC, and CC: Agent in your game (on servers too). See also: codex, agentlog.
